# فهرست پلاگین‌های جامعه MyBot

به فهرست رسمی **پلاگین‌های متن‌باز** برای **MyBot Studio** خوش آمدید — موتور ساخت ربات تلگرام بدون‌کد و خودمیزبان.

این مخزن، دایرکتوری مرکزی است که سازندگان، توسعه‌دهندگان و جامعه در آن، افزونه‌های قابل توسعه برای MyBot را ارائه، کشف و نگه‌داری می‌کنند.

> 🌐 **زبان‌ها:** [English](README.en.md) · [فارسی](README.fa.md) · [Русский](README.ru.md) · [العربية](README.ar.md)

## 🧩 نحوه کار

پلاگین‌ها بوم استودیوی بصری MyBot را با **نودهای سفارشی**، پنل‌های مدیریت، درگاه‌های پرداخت، ابزارهای تحلیل و اتصال‌دهنده‌های API خارجی گسترش می‌دهند.

هر پلاگین یک پوشه مستقل است که شامل:

1. `manifest.json` — فراداده (نام، نسخه، نویسنده، توضیحات، دسته، ورودی/خروجی و قلاب‌های UI).
2. هندلرهای بک‌اند (روتر FastAPI / منطق اجرای نود DAG).
3. کامپوننت‌های فرانت‌اند (نود بوم React یا اکستنشن داشبورد).

```
plugins/
├── my-awesome-plugin/
│   ├── manifest.json
│   ├── __init__.py
│   ├── node.py
│   └── README.md
```

### مثال‌ مانیفست (`manifest.json`)

```json
{
  "key": "live_weather",
  "name": "Live Weather Provider",
  "name_fa": "ارائهدهنده آبوهوای زنده",
  "description": "Adds a canvas node that fetches real-time weather for the user's location.",
  "description_fa": "افزودن نودی که آبوهوای لحظه‌ای بر اساس موقعیت کاربر را دریافت می‌کند.",
  "version": "1.0.0",
  "author": "YourName",
  "type": "toolkit",
  "icon": "Cloud"
}
```

Field reference (what `discover_installed_plugins()` reads): `key` (required; falls back to the folder name), `name`, `name_fa`, `description`, `description_fa`, `version`, `author`, `type` (`toolkit` default or `admin`), `icon` (Lucide icon, default `Puzzle`).

## 📁 ساختار پوشه‌ها

پلاگین‌ها بر اساس دسته‌بندی زیر سازماندهی شده‌اند (فایل `categories.json` مرجع واحدِ دسته‌هاست):

| پوشه | دسته | نمونه |
|---|---|---|
| `plugins/payments/` | درگاه‌های پرداخت و ارز دیجیتال | اتصال زارین‌پال، ترون، اتصال کیف پول |
| `plugins/analytics/` | آمار، رهگیری و داشبورد | شمارنده کاربران، لاگ رویدادها |
| `plugins/services/` | سرویس‌ها و APIهای خارجی | هوش مصنوعی، آب‌وهوا، وب‌هوک |
| `plugins/admin/` | مدیریت، ضداسپم و نظارت | بن کاربر، عضویت اجباری، هشدار ادمین |
| `plugins/messengers/` | پیام‌رسان‌ها و تیکتینگ | پشتیبانی آنلاین، پل بین پلتفرم |
| `plugins/community/` | بازی‌ها و ابزارهای عمومی | ماشین‌حساب، نودهای سرگرمی |

## 🤝 قوانین مشارکت و نگه‌داری

برای پویا و قابل‌اعتماد نگه‌داشتن این اکوسیستم:

1. **ارسال با Pull Request**: برای افزودن پلاگین، یک پوشه در `plugins/<id-pelagin>/` بساز و Pull Request بفرست. حتماً مستندات شفاف، اسکیمای پیکربندی معتبر و تست همراه داشته باشد.

2. **متن‌باز و غیرتجاری**: همه پلاگین‌های این مخزن تحت **GNU AGPL-3.0** (یا مجوز OSI سازگار) رایگان و متن‌باز هستند. پلاگین‌های **تجاری، پولی یا اختصاصی** در این فهرست پذیرفته **نمی‌شوند**. نویسندگان علاقه‌مند به توزیع تجاری یا کسب درآمد، باید سرویس، پلتفرم یا وب‌سایت جداگانه خودشان را راه‌اندازی کنند.

3. **نگه‌داری اجتماعی**: فرستادن پلاگین به این مخزن یعنی اجازه دهید جامعه، در صورت غیرفعال شدن سازنده اصلی، بتواند باگ‌ها را رفع، آن را با نسخه‌های جدید موتور همگام و به‌روزرسانی کند. تیم مرکزی MyBot پشتیبانی، تضمین ارزش یا مسئولیت حقوقی برای سرویس‌ها، تبلیغات، APIها یا محتوای پلاگین‌های طرف سوم را بر عهده نمی‌گیرد و آن را تأیید هم نمی‌کند.

4. **استانداردهای امنیت و کیفیت**:
   - بدون کد مبهم، رمزنگاری‌شده یا اجرای از راه دور (به جز APIهای سمت سرور مجاز).
   - بدون تله‌متری، جمع‌آوری داده غیرمجاز، ربودن توکن یا بک‌دور. هر PR تحت تحلیل امنیتی خودکار و بازبینی کد قرار می‌گیرد.

## 📦 نصب پلاگین در MyBot Studio

از داشبورد MyBot:

1. به **Plugins** از منوی کناری بروید.
2. عنوان پلاگین را جستجو کنید یا لینک پوشه/مخزن گیت‌هاب آن را پیست کنید.
3. **Install / Activate** را بزنید. نود فوراً روی بوم شما ظاهر می‌شود.
