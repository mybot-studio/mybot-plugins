# Каталог плагинов сообщества MyBot

Добро пожаловать в официальный каталог плагинов с открытым исходным кодом для **MyBot Studio** — визуального no-code движка для создания Telegram-ботов на собственном сервере.

Этот репозиторий — центральный индекс, где создатели, разработчики и сообщество публикуют и поддерживают модульные расширения для MyBot.

> 🌐 **Языки:** [English](README.en.md) · [فارسی](README.fa.md) · [Русский](README.ru.md) · [العربية](README.ar.md)

## 🧩 Как это работает

Плагины расширяют визуальный холст MyBot **кастомными узлами**, админ-панелями, платёжными шлюзами, инструментами аналитики и коннекторами внешних API.

Плагин — самодостаточная папка:
1. `manifest.json` — метаданные (название, версия, автор, описание, категория, входы/выходы, UI-хуки).
2. Бэкенд-обработчики (FastAPI-роутер / логика выполнения узла DAG).
3. Фронтенд (React-узел холста или расширение дашборда).

```
plugins/
├── my-awesome-plugin/
│   ├── manifest.json
│   ├── __init__.py
│   ├── node.py
│   └── README.md
```

### Пример манифеста (`manifest.json`)

```json
{
  "key": "live_weather",
  "name": "Live Weather Provider",
  "name_fa": "ارائهدهنده آبوهوای زنده",
  "description": "Adds a canvas node that fetches real-time weather for the user's location.",
  "description_fa": "افزودن نودی که آبوهوای لحظه‌ای بر اساس موقعیت کاربر را دریافت می‌کند.",
  "version": "1.0.0",
  "author": "YourName",
  "type": "toolkit",
  "icon": "Cloud"
}
```

Field reference (what `discover_installed_plugins()` reads): `key` (required; falls back to the folder name), `name`, `name_fa`, `description`, `description_fa`, `version`, `author`, `type` (`toolkit` default or `admin`), `icon` (Lucide icon, default `Puzzle`).

## 📁 Структура папок

Плагины организованы по категориям (единый источник — `categories.json`):

| Папка | Категория | Примеры |
|---|---|---|
| `plugins/payments/` | Платёжные шлюзы и крипто | ZarinPal, TRON, кошельки |
| `plugins/analytics/` | Аналитика и дашборды | счётчики пользователей, логи событий |
| `plugins/services/` | Внешние сервисы и API | AI, погода, вебхуки |
| `plugins/admin/` | Администрирование и антиспам | баны, обязательные подписки, алерты |
| `plugins/messengers/` | Мессенджеры и тикеты | онлайн-поддержка, мосты |
| `plugins/community/` | Игры и утилиты | калькуляторы, развлекательные узлы |

## 🤝 Правила участия

1. **Pull Request**: добавьте папку `plugins/<plugin-id>/` с документацией, схемой конфигурации и тестами.

2. **Открытый исходный код и некоммерческое использование**: все плагины здесь бесплатны и открыты под **GNU AGPL-3.0** (или совместимой OSI-лицензией). **Коммерческие, платные или проприетарные** плагины **не принимаются** в этот публичный каталог. Авторам, желающим монетизировать свои расширения, следует запускать собственные сервисы, платформы или сайты.

3. **Поддержка сообществом**: отправка плагина разрешает сообществу исправлять, поддерживать и обновлять его под новые версии движка, если автор станет неактивен. Команда MyBot не несёт юридической ответственности за сторонние сервисы, рекламу, API или контент сторонних плагинов.

4. **Безопасность и качество**: без обфусцированного/шифрованного/удалённо выполняемого кода, без телеметрии, кражи токенов и бэкдоров. Каждый PR проходит автоматический security-анализ и ревью кода.

## 📦 Установка плагина

В дашборде MyBot: **Plugins** → поиск или вставка ссылки → **Install / Activate**. Узел сразу появится на холсте.
